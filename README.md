# The Test tab

This repository is the HomeServer's Test tab: every xenia-kit part appears on one page, wearing the crown's skin. Your HomeServer's Woodpecker builds its releases. You and your assistant can copy it to make your own tab.

1. Copy these files into a new repository on your HomeServer's Forgejo at https://git.home.arpa. Name the repository `cartridge-<id>` and use its `main` branch. The unchanged example is `cartridge-test`.
2. Rename the tab: replace `test` in `cartridge.json` and `static/pack.css` with your id; change the display name and `install.bin` path in `cartridge.json`. Replace `src/fragment.rs` with your own composition of xenia-kit parts, using your new id in its fragment. Set `source.release_repo` to your Forgejo account and repository, for example `yourname/cartridge-garden`, and keep `source.ref` as `main`. Change the package name in `Cargo.toml` to exactly match the repository name, `cartridge-<id>`, then regenerate and commit `Cargo.lock`. Keep `build.rs` and the source SHA in health. The example stylesheet is not declared in the manifest and has no visual effect until you declare it as described in the xenia-kit guide.
3. Open https://ci.home.arpa, sign in with Forgejo and activate the repository. In Forgejo Settings → Applications create a token with repository write permission for Releases. Add it as the one Woodpecker repository secret `FORGEJO_TOKEN`, never to your repository or chat. The local runner executes the commands of repositories you activate as its own user without container isolation, so activate only code you trust. Push your requested changes to `main` and wait for a successful Woodpecker run.
After the first Release, add the tab from your HomeServer's + → Make one. The owner can widen the tab's visibility in Coronatio; later pushes produce Releases for the next update.

Read [Your own tab](https://docs.home.arpa) under Services in your HomeServer's documentation for the full pipeline and admission steps. For an assistant: show the person the Woodpecker run and the tab; push to `main` only when the person asked for that change.
